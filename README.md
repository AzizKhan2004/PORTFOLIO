 — Modern Responsive Portfolio (HTML & CSS)

A clean, accessible, and responsive portfolio template built with semantic HTML and handcrafted CSS. Perfect as a personal site, portfolio starter, or static resume.

## Features
- Semantic, accessible HTML structure
- Responsive layout for mobile, tablet, and desktop
- Modern CSS: gradients, glass effect, and smooth spacing
- Lightweight and easy to customize
- No frameworks required — pure HTML & CSS
- Optional progressive enhancements (Sass, build tools) described below
